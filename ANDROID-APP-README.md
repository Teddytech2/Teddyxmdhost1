# TEDDY-XMD Android app

This project builds a real installable Android APK. The app is a native Android shell with a full-screen WebView that opens the configured dashboard without a browser address bar. The dashboard content and features are served by your website.

## Current destination

The current app destination is:

`https://teddyxmdhost1-39f912857ad8.herokuapp.com/`

The app reads its remote destination from:

`https://teddyxmdhost1-39f912857ad8.herokuapp.com/app-config.json`

The app config currently lives in `public/app-config.json`. To point the installed app to a different dashboard later, change `websiteUrl` and `allowedHosts` in that file and deploy the config host. The APK does not need rebuilding as long as the original config URL remains online.

## Build the actual APK

1. Upload the contents of this ZIP to the root of the `Teddyxmdhost1` GitHub repository and push to `main`.
2. In GitHub, open **Actions** and run **Build TEDDY-XMD Android APK** (or let it run after the Android workflow files are pushed).
3. Wait for the workflow to finish successfully. It builds a signed debug APK and uploads a downloadable GitHub Actions artifact named `TEDDY-XMD-Android-APK`.
4. The workflow also copies the APK to `public/downloads/TEDDY-XMD.apk` and commits it to `main`.
5. Redeploy the Heroku dashboard so the APK file is served by the website.
6. Visit the website. The Install TEDDY-XMD popup and buttons appear only after the server confirms that the APK file exists.

The Android APK is not included as a precompiled binary in this source ZIP. It is generated by the GitHub Actions build. Until that build succeeds and the updated site is deployed, the install popup remains hidden and the download route returns a clear 404 message rather than HTML.
